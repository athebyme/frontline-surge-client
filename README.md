# frontline-surge-client

Играбельная альфа 0.5.3 для командного матча в XXI веке. Две стороны встречаются в промышленной долине Сен-Лорана площадью 560 × 460 м. Пехота сражается за улицы и склады, водители возят материалы, разведчик поднимает квадрокоптер над кварталом. В матче можно сменить занятие в любой момент. Роль и экипировку выбираешь сам.

## Подключиться к матчу

Запусти `FrontlineSurge.exe` из Windows-комплекта Client или выполни `cargo run --release --locked` в этой папке. Введи позывной, выбери команду и укажи адрес хоста. Если сервер работает на том же компьютере, подходит `127.0.0.1:8787`. Для игры с друзьями нужен доступный им адрес хоста и TCP-порт сервера. Клиент 0.5.3 использует протокол 5.

Для локальной игры с ботами сначала запусти отдельный процесс сервера. Например, Windows-сервер с четырьмя ботами запускается командой `FrontlineServer.exe --bots 4`. Подключись к нему из меню игры. В репозитории сервера есть инструкции для Windows и Linux, параметры матча и установка на VPS. [Выделенный сервер Frontline Surge](https://github.com/athebyme/frontline-surge-server)

Настройки доступны из главного меню и по Esc в матче. Можно выбрать профиль или отдельно настроить тени, детализацию моделей, дальность травы, фактуру поверхностей, насыщенность, режим экрана, показ FPS и чувствительность мыши. Игра сохраняет выбор для следующего запуска.

В танке и БТР колесо приближает внешний обзор. Ещё один шаг колеса на предельном приближении включает центральный прибор наблюдения. Прокрутка назад возвращает внешний вид. Y переключает вид сразу. В приборе N переключает обычное изображение, ночное видение и тепловизор. Пушка и пулемёт следуют стабилизированному направлению во время поворота корпуса. Кольцо пулемёта учитывает ближайшее препятствие в текущем кадре. ЛКМ запускает снаряд, ПКМ — пулемёт. Оба расходуют свой боезапас. Вокруг попаданий остаются надколы, а от выбитых блоков — низкие проходимые обломки.


### Боевой интерфейс

Верхняя строка показывает счёт, время и азимут камеры. В левом нижнем углу крест обозначает здоровье, молния — выносливость. Справа крупное число показывает патроны в магазине, малое — запас. Клавиша **Tab** открывает списки команд, личные очки, фраги, помощь и смерти.

В ленте фрагов между позывными стоит силуэт оружия. Для огня с борта рядом видны машина и её орудие, для наезда — машина и знак удара. Расшифровка всех силуэтов находится в **Управление → Фраги**. Такие же силуэты оружия видны рядом с боезапасом бойца и в выборе снаряжения. Перенося материалы в **I / T**, сверяй ячейки рюкзака слева, кузова в середине и количество справа.

В мастерской после **E** сразу открываются боеприпасы. Выбери изображение изделия слева. Справа появятся его модель, изменения запаса или характеристик и остаток каждого материала после изготовления. Для НПЗ тот же экран показывает ход партии, свободное место в рюкзаке и остаток в приёмнике. На вкладке снаряжения наведение на прицел или цевьё показывает изменения поля зрения, подвижности и разброса.

В мастерской карточка показывает выбранное изделие, стоимость и значения до и после изготовления. В ленте устранений между позывными рисуется силуэт оружия. Для бортового вооружения рядом видна и машина. В стройке метка на кромке указывает точку стыка.

## Собрать клиент

Проверено на Rust 1.88. Для Windows подходят Visual Studio Build Tools с компонентом C++ и Windows SDK либо MinGW-w64. Для нативного Linux-клиента нужны X11, OpenGL и обычный системный линковщик. Пространственный звук реализован в Windows-сборке.

```sh
cargo build --release --locked
cargo test --all-features --locked
python3 tools/check_level.py
```

На Windows запускай `target/release/frontline-surge.exe`, на Linux — `./target/release/frontline-surge`. Шрифт, текстуры, модели, шейдеры и карта встроены в программу.

Скрипт ниже собирает Windows x64, проверяет формат исполняемого файла и кладёт `FrontlineSurge.exe` и уведомления о сторонних компонентах в `dist/windows-client/`. На Windows используй `python` или `py -3`. Для кросс-сборки на Linux потребуются цель Rust `x86_64-pc-windows-gnu` и MinGW-w64 с `windres`.

```sh
python3 tools/build_windows.py
```

Сервер хранит эталон общих исходников и описания уровня. Их копии закреплены в клиенте, поэтому его можно собирать из одного клона. Если оба репозитория лежат рядом, выполни проверку перед публикацией совместимых изменений.

```sh
python3 tools/check_server_contract.py ../frontline-surge-server
```

## Внести изменение

Создай рабочую ветку и открой pull request (MR) в `main`. Сливай его после успешной проверки `client-test-build`: она запускает тесты и собирает release-клиент на Windows x64. Прямые push и force-push в `main` запрещены. [Как включить защиту ветки в GitHub](docs/main-protection.md).

## Что проверить в первом матче

В режиме B наведи прицел на свою целую нижнюю стену. Полупрозрачная секция покажет второй ярус. Щёлкни ЛКМ, чтобы построить его. Разрушение опоры открывает проход для всех игроков.

Для проверки наката разгони машину на ровном участке и нажми F. Колёса продолжают вращаться, пока машина катится. В танке и БТР поверни камеру в сторону: метка прицела движется вместе с башней. Восстановить союзную машину для повторного заезда можно через F2.

**Проверь стену с двух сторон.** Возьми основной танк или гранату и выбери боковую стену склада. Фасад собран из отдельных блоков. Открой пролом и попробуй пройти через него. Опора, которая теряет связь с фундаментом, может увлечь за собой часть стены или крыши. У домов есть готовые двери и окна. Размер блока около 0,8 м. Мелкие падающие обломки — визуальный эффект. Сервер хранит потерянные блоки и проверяет движение и попадания по оставшейся геометрии.

**Запусти снабжение.** Собери дерево и металл, в K выбери НПЗ, затем поставь его на открытом месте. Возьми четыре единицы нефти у промысла. Рядом со своим НПЗ запусти переработку и через 12 секунд забери шесть единиц топлива. Можно заправить машину на месте или сделать рейс на грузовике. В мастерской доступны боеприпасы, гранаты и две ступени улучшения машин.

**Подними дрон.** На открытом месте нажми J. Боец подбросит аппарат, и после взлёта откроется камера. J оставляет дрон висеть и возвращает управление бойцом. Нажми J ещё раз в радиусе 65 м, чтобы продолжить тот же полёт. Батарея расходуется и при зависании. ЛКМ передаёт союзную метку на 12 секунд, Z меняет зум. X один раз за вылет тратит 14 секунд заряда и поражает открытых врагов и технику рядом с дроном. Shift+J отзывает его. Противник может сбить аппарат, даже когда ты вышел из камеры.

## Как пользоваться грузом

У своей грузовой машины открой **I**, выбери материал, нужное количество и направление. Для крафта сначала переложи материал из кузова в рюкзак. Например, выгрузи 8 металла, возьми 6 дерева и выбери мастерскую в K. Чтобы освободить только часть ячейки, выбери в I материал и нажми «Выбросить». Стопка появится в мире, напарник сможет её подобрать. Карта M показывает ближайшие источники металла.

## Быстрая проверка разработки

В локальном матче **F2** открывает панель с ботами, ресурсами, восстановлением, FPS и свободной камерой. Выбирай материал и количество. Для камеры используются WASD, Q/E по высоте и Shift для ускорения. Esc возвращает к бойцу. Обычный выделенный сервер запускается с отключёнными правами разработки. При самостоятельном запуске добавь `--dev-local` и подключись к `127.0.0.1`, чтобы получить полномочия. Боты делят 12 мест с людьми.

Целевой режим — уничтожение базы противника. Его дизайн и переход между сессиями описаны в docs/ideas. В поставляемой 0.5 матчи завершаются по правилам командного боя.

## Ресурсы и документация

Редактируемая геометрия, исходная модель бойца для Blender и лист рисованных материалов `field-materials.svg` лежат в `tools/art-source/`. Потребуются Node.js, Python 3 с NumPy и Pillow, а также Inkscape с командой `inkscape` в PATH. После изменения визуальных исходников запусти из корня проекта:

```sh
python3 tools/art-source/bake_materials.py  # Inkscape CLI, NumPy, Pillow
node tools/export_art.cjs
python3 tools/pack_actors.py
```

Канонический уровень обновляется вместе с сервером. Шрифт поставляется с его исходной лицензией в `assets/FONT-LICENSE.txt`. Собранные уведомления для Windows GNU находятся в `THIRD-PARTY.txt`. При выпуске скрипт повторно собирает тексты из зависимостей Cargo выбранной версии и сохраняет их рядом с программой.
