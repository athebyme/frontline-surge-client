# Устройство клиента

Клиент подключается к выделенному процессу по TCP, отправляет ввод и рисует состояние мира. Единицы игры — метры и секунды. Авторитетная симуляция ведёт урон, перемещение, ресурсы, состав команд и результат раунда. [Репозиторий выделенного сервера](https://github.com/athebyme/frontline-surge-server)

| Часть | Исходники клиента | Что проверить |
|---|---|---|
| Вход, ввод, сглаживание и камеры | `src/main.rs`, `src/chase.rs` | Подключение, захват мыши, вид из техники и возврат к бойцу |
| Протокол | `src/net.rs`, `src/wire.rs`, `src/world_wire.rs` | Отказ при несовместимой версии, позднее получение разрушений и стопок, сброс карты между раундами |
| Карта и разрушения | `src/fracture.rs`, `src/world.rs`, `src/world_fracture.rs`, `assets/level.json` | Форма проёма должна совпадать с серверными коллизиями и геометрией у второго клиента |
| Оружие и техника | `src/arsenal.rs`, `src/actors.rs`, `src/world_vehicles.rs`, `src/sound.rs` | Режим огня, оптика, ходовая, повреждения, направление звука |
| Дрон | `src/drone_view.rs`, `src/shaders/drone_feed.*` | Ориентация картинки, приближение, батарея, заряд и видимость меток для союзников |
| Меню, HUD и производство | `src/ui.rs`, `src/crafting.rs`, `src/stash_ui.rs`, `src/tactical_map.rs` | Выбор команды, результаты переноса, готовое топливо, открытие и закрытие окон |
| Отладка | `src/debug_ui.rs`, `src/main.rs` | Сервер определяет доступные команды. Выход из свободной камеры возвращает управление бойцу |
| Визуальные исходники | `src/shaders/`, `tools/art-source/`, `tools/pack_actors.py`, `tools/export_art.cjs` | Силуэты обеих команд, цикл освещения, анимация и сохранность UV при экспорте |

## Синхронизация

Первый пакет содержит состояние мира. Надёжные обновления карты применяются в порядке получения, промежуточные снимки положений могут заменяться. Смена раунда требует новой исходной карты. Канонические файлы протокола, зданий, снаряжения и уровня ведутся в серверном репозитории. Перед совместным выпуском сравни их командой из [README](../README.md).

## Проверка

Запусти `cargo test --all-features --locked` и `python3 tools/check_level.py`. Для камеры и интерфейса подключись к реальному процессу сервера. Проверь в отдельном окне подключение к уже изменившейся карте, закрытие модальных окон и восстановление управления. Проверку звука проводи в Windows-клиенте с устройством вывода.
