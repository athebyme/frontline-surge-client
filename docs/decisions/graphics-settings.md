# Графика на компьютере игрока

«Настройки» открываются из главного меню и по Esc во время боя. При смене профиля карта продолжает отображаться рядом с панелью, чтобы можно было оценить результат сразу. Профиль меняет четыре параметра качества. Насыщенность, чувствительность мыши, счётчик FPS и режим окна сохраняют выбранные игроком значения.

| Параметр | Быстрый | Баланс (по умолчанию) | Качество |
|---|---|---|---|
| Тени карты и техники | Проход теней отключён | Карты 1024², сглаживание по четырём соседям | Карты 2048², плавно взвешенный фильтр 3×3 |
| Дальность подробных моделей с упрощённым вариантом | 56 м | 93 м | 150 м |
| Дальность отображения травы | 42 м | 88 м | 140 м |
| Микрофактура поверхности вблизи | Отключена | Ослаблена | Полная |

Индивидуальное изменение одного из четырёх параметров доступно в том же меню. Для разрушенных объектов клиент сохраняет актуальную геометрию проломов. Сервер одинаково проверяет столкновения и попадания при любом качестве.

Клиент сохраняет выбор в JSON после изменения. На Windows файл находится в `%APPDATA%\frontline-surge\settings.json`, на Linux — в `$XDG_CONFIG_HOME/frontline-surge/settings.json` или `~/.config/frontline-surge/settings.json`. Переключения по F3 и F11 также сохраняются. При недоступной записи изменения действуют до выхода из клиента, а панель показывает сообщение.

Для проверки открыть настройки в главном меню, сменить профили в обе стороны и сравнить траву, фактуру и края теней. Войти в матч, открыть настройки из паузы, изменить значения и вернуться в бой. После перезапуска проверить профиль, режим экрана и чувствительность.


## Тени техники и приборы наблюдения

Рельеф получает два слоя теней. Дома и постройки остаются в кэше. Для транспорта клиент сравнивает текущие матрицы корпуса, колёс, башни и ствола в пределах теневой карты. При их изменении перерисовывается только этот слой, до отрисовки того же видимого кадра. Если объект исчез, слой очищается. Центры обеих проекций привязаны к сетке источника света. Фильтр сравнивает глубину по плоскости поверхности, в том числе на наклонных гранях.

В бронетехнике клавиша N переключает дневную оптику, ПНВ и бело-горячий тепловизор. ПНВ усиливает освещённость видимой сцены. В тепловизоре бойцы и техника различаются по тепловой сигнатуре. Занятая машина горячее припаркованной, остов холоднее. Приборы используют тот же буфер глубины, что и обычный вид. Сплошная стена закрывает цель, а в проёме остаётся видна открытая часть. Прицел и подписи накладываются после обработки кадра.
